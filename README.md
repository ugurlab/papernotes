# PaperNotes

A Desk & Bench tool for research articles, notes and quotations.

- [Tool page](https://ugurlab.github.io/papernotes/)
- [Open PaperNotes](https://ugurlab.github.io/papernotes/app/)

## Use

Open the web app or extract the release ZIP and open `app/index.html` in your browser. Add an article by DOI, choose a writing section, and record notes or quotations.

The archive stays in your browser. DOI lookup sends the DOI to Crossref, Europe PMC and, when needed, OpenAlex. Manual entry and archive browsing work offline. Use JSON backup and import to move records between browsers or devices.
